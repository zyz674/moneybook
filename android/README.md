# 安卓 App（离线版）

**装到手机上之后，不需要电脑、不需要服务器、不需要联网**：
微信/支付宝/银行的付款通知会自动记账，每天定点在手机上弹出当日账单，数据只存在这台手机里。

## 它和另外两个版本的区别

| | 本 App（安卓） | 网页版 | 服务端版 |
| --- | --- | --- | --- |
| 自动抓流水 | ✅ 通知一进来就记 | ❌ | ✅ |
| 每天定点账单 | ✅ 手机本地弹通知 | ❌ | ✅ |
| 需要常开的机器 | **不需要** | 不需要 | 需要 |
| 数据在哪 | 手机里 | 浏览器里 | 你的电脑上 |

## 怎么装

### 方式一：直接下载（推荐，不用装开发工具）

**下载地址：[moneybook.apk](https://github.com/zyz674/moneybook/releases/latest/download/moneybook.apk)**

手机上打开这个链接就能下（不用登录 GitHub），安装时如果提示「禁止安装未知应用」，
按提示允许一次即可。也可以从 [Releases](https://github.com/zyz674/moneybook/releases) 页面下载。

> 想自己编译同样的包，可以在 [Actions](https://github.com/zyz674/moneybook/actions/workflows/android.yml)
> 里看构建记录（那里也能下 Artifacts，但需要登录 GitHub）。

> 这个 APK 用的是调试签名，够自己人和朋友用；要上架应用商店才需要另外配正式签名。

### 方式二：自己编译

```bash
python tools/build_pages.py          # 先把网页资源同步进安卓工程
python tools/make_android_icons.py   # 生成图标
cd android && gradle assembleDebug   # 或用 Android Studio 打开 android/ 目录直接运行
```

## 装好后要做两件事

### 1. 开启「通知读取权限」（关键）

打开 App → 「设置」→ 手机 App 区块 → 点 **「开启通知读取权限」** → 在系统列表里找到「记账本」并允许。

开了之后，每一笔微信/支付宝付款都会自动记下来，并在通知栏弹一条「已记 1 笔」。

### 2. 把 App 加入白名单（国产 ROM 必做）

小米 / 华为 / OPPO / vivo 等系统会杀后台，建议：

- 设置 → 应用管理 → 记账本 → **自启动**：允许
- **电池 / 省电策略**：改为「无限制」或「允许后台运行」
- 最近任务里给记账本**加锁**（下拉卡片点锁图标）

不做这一步也能用，但后台可能被系统清掉，导致「每天定点弹账单」不稳定。

## 它是怎么工作的

```
微信/支付宝/银行 发通知
        ↓（系统绑定，不需要常驻前台）
NotifyListener  →  NotifyQueue（本地队列，App 被杀也不丢）
        ↓（常驻服务每 5 秒取一次）
CaptureService 里的网页逻辑：解析金额/商户/方向 → 规则分类 → 去重 → 存本地
        ↓
每天定点：AlarmManager + 页面内定时双保险 → 生成本地账单 → 系统通知弹出
```

界面、解析、规则引擎、报表统计**全部复用网页版那一份代码**（`src/moneybook/webui/`），
App 只是个壳：WebView + 通知监听 + 定时。所以网页版修了 bug，重新编译一次 App 就同步生效。

## 认不出来的通知怎么办

通知里没有金额、或格式不认识的（比如「您的账户发生一笔交易，详情请登录查看」），
**不会丢**，会进「待录入」队列，首页会提示。点开看到原文，补上金额和商户就入账，
并且会自动记住这个商户。

## 隐私

- 数据全部存在手机本地（WebView 的 IndexedDB），**App 不联网**（只有你主动配了推送通道才会联网推送）
- 不需要注册、不上传、没有服务器
- 通知监听是安卓官方能力，只读取通知的标题和正文
- 换手机前：设置 → 维护 → **导出 CSV** 备份

## 已知限制

- 只支持安卓；**iPhone 做不到自动读通知**（iOS 系统限制，见 `docs/iPhone使用指南.md`）
- 部分支付宝通知不带金额，这类会走「待录入」补录
- 调试签名不适合上架商店；要正规发布需要自己的 keystore
