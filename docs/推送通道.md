# 推送通道配置

在「我的 → 推送通道」里填 JSON 数组（也可直接改 `config.json` 的 `notify.channels`），
填完点「发送测试」，收到消息就说明通了。多个通道可以同时配，一条消息会逐一发送。

```json
{
  "notify": {
    "channels": [
      { "type": "bark", "url": "https://api.day.app/你的KEY", "group": "记账本", "sound": "birdsong" }
    ]
  }
}
```

---

## Bark（iPhone，最推荐）

App Store 搜 Bark 安装，打开就能看到自己的推送地址。

```json
{ "type": "bark", "url": "https://api.day.app/abcdefg", "group": "记账本", "sound": "birdsong", "level": "active" }
```
- `url`：也可以写成 `https://api.day.app` 再单独给 `key`
- 自建 Bark 服务器就把 url 换成自己的地址

## Server 酱（微信推送）

[sc3.ft07.com](https://sct.ftqq.com) 拿 SendKey：

```json
{ "type": "serverchan", "key": "SCTxxxxxxxxxxxxxxxx" }
```

## PushPlus（微信）

```json
{ "type": "pushplus", "token": "你的token", "template": "txt" }
```

## ntfy（安卓 / 自建，开源）

手机装 ntfy App，订阅一个足够随机的主题名：

```json
{ "type": "ntfy", "server": "https://ntfy.sh", "topic": "moneybook-8f3k2n", "priority": 3 }
```

## Telegram

```json
{ "type": "telegram", "token": "123456:ABC-DEF...", "chat_id": "你的chatid" }
```

## 企业微信群机器人

群 → 右上角 → 群机器人 → 添加 → 复制 Webhook 地址：

```json
{ "type": "wecom", "webhook": "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxx" }
```

## 钉钉群机器人（支持加签）

```json
{ "type": "dingtalk", "webhook": "https://oapi.dingtalk.com/robot/send?access_token=xxxx", "secret": "SECxxxx" }
```

## 飞书群机器人

```json
{ "type": "feishu", "webhook": "https://open.feishu.cn/open-apis/bot/v2/hook/xxxx" }
```

## 自定义 Webhook（接自己的服务 / IFTTT / n8n）

会 POST 这样的 JSON：`{"title": ..., "body": ..., "text": ..., "kind": "daily"}`

```json
{ "type": "webhook", "url": "https://example.com/hook", "headers": { "Authorization": "Bearer xxx" } }
```

## 只打印到控制台（调试用）

```json
{ "type": "console" }
```

---

## 什么时候会推送

| 场景 | 触发条件 | 内容 |
| --- | --- | --- |
| 每日账单 | `reports.daily_times`（默认 12:00） | 区间收支、分类占比、最大支出、本月预算进度 |
| 周报 | 默认周一 09:00 | 本周至今汇总 |
| 月报 | 默认每月 1 日 09:00 | 上个月整月汇总 |
| 大额支出 | 每笔超过 `alerts.large_amount` 元 | 逐笔列出 |
| 测试 | 界面上点「发送测试」 | 固定文案 |

推送记录都能在「我的 → 最近推送」里查到，包含每个通道的成功/失败与返回内容。
