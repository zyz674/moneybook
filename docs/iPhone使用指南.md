# iPhone 使用指南

iPhone 上没有后台服务，所以分两种玩法：**点链接就用**（零安装）和**接到电脑上的服务端**（全自动）。
大多数人的用法是：**平时用第一种，想要全自动再把第二种接上**。

---

## 一、最快：点开链接就用（纯前端版）

### 1. 打开并装到桌面

1. 用 **Safari** 打开 <https://zyz674.github.io/moneybook/>
2. 点底部「分享」按钮 → 「添加到主屏幕」→ 添加
3. 桌面上会多一个「记账本」图标，**点开是全屏的，和 App 一样**

> 一定要用 Safari。iPhone 上 Chrome / 微信内置浏览器不支持「添加到主屏幕」。

### 2. 把账单导进来

先在手机上导出账单（这一步在支付宝/微信 App 里做）：

| 从哪导出 | 路径 | 拿到什么 |
| --- | --- | --- |
| **微信** | 我 → 服务 → 钱包 → 账单 → 右上角「常见问题」→ 下载账单 → 选「用于个人对账」→ 填邮箱 | 邮件里一个 **zip**（**有密码**，密码会通过短信/微信发给你） |
| **支付宝** | 我的 → 账单 → 右上角「…」→ 开具交易流水证明 → 选「用于个人对账」→ 填邮箱 | 邮件里一个 **zip**（无密码） |

然后在 iPhone 上：

1. 打开「邮件」App，找到那封账单邮件，**长按附件 → 存储到「文件」**
2. 打开「文件」App，找到刚存下的 zip：
   - **支付宝的 zip：不用解压**，回到记账本点「导入账单」直接选这个 zip 就行
   - **微信的 zip：长按 → 解压**，会弹窗要密码，输入短信里那串密码，得到 CSV
3. 回到记账本（桌面图标），点右上角 **「导入账单」**，选那个 zip 或 CSV
4. 几秒后就出账了：分类、占比、走势全都算好

> 一个月导一次就够了。每次都只导入新的部分，**重复导入会自动去重，不会记两遍**。

### 3. 平时怎么用

- **点右下角「＋」**：随手记一笔
- **点任意一条流水**：改分类、改备注、删除。改过一次的商户，**下次自动归到同一类**
- **「流水」页**：按天翻，可以按微信/支付宝/银行、按分类筛
- **「统计」页**：每日支出与累计、分类排行、常去的商户（点商户可批量改分类）、固定支出（自动续费）
- **「设置」页**：导入账单、月度预算、推送通道、分类规则管理

### 4. 备份（重要）

数据存在 **Safari 的本地存储**里，不在云端。所以：

- **换手机、清理 Safari 数据、卸载浏览器之前**，先到「设置 → 维护 → 导出 CSV」，存到「文件」或 iCloud
- 平时也可以一个月导出一次留档
- 不要用「清除历史记录与网站数据」去清它——会一起清掉账本

## 二、让它更顺手：三个快捷指令

### 快捷指令 1：点一下就记一笔（配合桌面图标/轻点背面）

纯前端版支持**用链接直接记账**：

```
https://zyz674.github.io/moneybook/#q=12.5 肯德基
```

打开这个链接，就会自动记一笔「支出 12.50 餐饮/快餐 肯德基」，并弹提示。

做法：
1. 「快捷指令」App → ＋ → 添加动作 **要求输入**（类型：文本，提示「这笔花了多少？在哪花的？」）
2. 添加动作 **URL 编码**（输入上一步的「提供的输入」）
3. 添加动作 **打开 URL**，地址填：
   `https://zyz674.github.io/moneybook/#q=` 后面接上一步编码后的文本
4. 改名「快记一笔」
5. 设置 → 辅助功能 → 触控 → **轻点背面** → 轻点两下 → 选「快记一笔」

以后敲两下手机背面，输入 `35.8 美团`，就记好了。写法很随意：

```
12.5 肯德基     -> 支出 12.50 餐饮
35 打车         -> 支出 35.00 交通
工资 8500       -> 收入 8500.00
超市 128.4      -> 支出 128.40 日用百货
```

### 快捷指令 2 / 3：截图 OCR、每天自动弹账单

这两个需要电脑上跑着服务端版（见下一节），配置步骤写在 `docs/iOS快捷指令.md`。

## 三、想要全自动：把服务端接上

**「每 3 小时自动抓流水 + 每天定时推送账单」必须有一台一直开着的机器**
（iPhone 不能常驻跑 Python 服务）。典型做法：

1. 电脑 / NAS / 服务器上跑服务端版（`run.cmd` 或 Docker，见 README）
2. iPhone 和电脑连同一个 WiFi，Safari 打开 `http://电脑的IP:8787`
3. 出门在外也想看：两边都装 **Tailscale**，用 Tailscale 的 IP 访问，就等于随身带着

接上之后就能用：

- **安卓那套通知抓取**（iPhone 不行，这是系统限制）
- **每天 0 点和 12:00 自动推送账单** → 推到 Bark（iPhone 通知）或 Server 酱（微信）
- **快捷指令定时拉账单**：个人自动化 → 特定时间 → 获取 URL 内容 → 显示通知，不用打开 App

> ⚠️ 两个版本的数据是**各自独立**的：点链接版存在 iPhone 浏览器里，服务端版存在电脑上。
> 想只看电脑那份，就直接用 Safari 打开电脑地址；不建议两边同时记，容易对不上。

## 四、常见问题

**导入后没数据 / 提示没读出流水？**
- 确认选的是「用于个人对账」导出的 CSV 或 zip，不是截图、PDF、也不是「账单详情」截图
- 微信的 zip 有密码，需要先在「文件」App 里解压出 CSV
- 文件是不是被改过后缀？改成 `.csv` 再试

**会不会把我的账单传到网上？**
不会。纯前端版所有解析和存储都在你手机浏览器里完成，连这个项目的服务器都没有（它只是个静态网页）。
详见 `SECURITY.md`。

**换手机了怎么办？**
先在旧手机上「导出 CSV」，在新手机的记账本里重新导入即可（分类规则会按商户名自动重新套上）。

**能和朋友共用吗？**
不能，也不建议——每个人的账本存在自己手机里，互相看不到。
`docs/部署与使用.md` 里有说明。
