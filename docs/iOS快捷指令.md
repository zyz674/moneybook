# iPhone 快捷指令配置（免开发）

> 想先用起来？看 `docs/iPhone使用指南.md`——那里有「点链接就用」的纯前端版，
> 配合下面的「快捷指令 A」可以做到敲两下手机背面就记一笔，完全不需要服务器。
> 本文其余部分（截图 OCR、定时账单）需要电脑上跑着服务端版。

iPhone 不允许任何 App 在后台读取微信/支付宝的数据，这是系统限制。
但用「快捷指令 + 个人自动化」，可以做到**接近自动**：一键记账、每天定点弹账单、截图自动识别。

先把「服务器地址」记下来（记账本启动时打印、或在手机浏览器打开记账本后「我的」页能看到），
下面示例统一用 `http://192.168.1.100:8787`。如果设了口令，把 `&token=你的口令` 加到每个链接后面。

---

## 快捷指令 A：一键快记（30 秒记一笔）

1. 打开「快捷指令」App → 右上角 **＋**
2. 添加动作 **要求输入**
   - 输入类型：`文本`
   - 提示：`花了多少？在哪花的？`（例如输入 `12.5 肯德基`）
3. 添加动作 **获取 URL 内容**
   - URL：`http://192.168.1.100:8787/quick?format=text&text=` 后面接上一步的「提供的输入」
     （在键盘上方选「提供的输入」变量；中文和空格快捷指令会自动转义）
   - 方法：`GET`
4. 添加动作 **显示通知**，内容选「URL 内容」
5. 点右上角改名：`快记一笔`

**让它更好按**：设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下 → 选「快记一笔」。
以后付款完，敲两下手机背面，输入 `35.8 美团` 就记好了，服务端会自动识别金额、方向、分类。

能识别的写法很随意：

```
12.5 肯德基        -> 支出 12.50 餐饮/快餐
35 打车            -> 支出 35.00 交通/打车
工资 8500          -> 收入 8500.00 收入/工资
超市 128.4         -> 支出 128.40 日用百货/超市
退款 99            -> 收入 99.00 收入/退款
```

## 快捷指令 B：每天定点弹账单（不用打开 App）

1. 新建快捷指令，添加动作 **获取 URL 内容**
   - URL：`http://192.168.1.100:8787/api/report/preview?mode=auto`
   - 方法：`GET`（返回纯文本账单）
2. 添加动作 **显示通知**，内容选「URL 内容」，标题写「今日账单」
3. 改名 `看账单`
4. 切到「自动化」标签页 → **＋** → **特定时间**
   - 时间：`00:00`，重复：每天
   - 选「立即运行」并关掉「运行前询问」（iOS 15+ 支持免确认）
   - 下一步 → 选择刚才的 `看账单` 快捷指令
5. 再建一个 `12:00` 的自动化，同理

这样每天 0 点和 12 点，iPhone 会自己弹出账单摘要，和你电脑/手机上的推送互不冲突。

## 快捷指令 C：截图 OCR 自动记账

1. 新建快捷指令
2. 添加动作 **从图像中提取文本** → 选择「最近的截图」
3. 添加动作 **获取 URL 内容**
   - URL：`http://192.168.1.100:8787/quick?format=text&text=` 接上一步的「文本」
4. 添加动作 **显示通知**
5. 切到「自动化」→ **＋** → **App** → 选「微信」和「支付宝」→ 触发时机勾「已关闭」
   → 选「立即运行」→ 选择这个快捷指令

用法：付款完成后截个图（付款成功页），退出微信/支付宝，快捷指令自动读截图里的文字并记账。
配合「设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下 → 截屏」会更顺手。
如果截图里没有金额（比如只截了聊天记录），服务端会返回「没识别出交易」，不会乱记。

---

## 快捷指令 D：只想在手机上看看

直接 Safari 打开 `http://192.168.1.100:8787` → 分享 → **添加到主屏幕**，
就会有一个带图标的「记账本」，全屏使用、可看明细/统计/改分类/上传账单。

## 常见问题

**连不上？**
- iPhone 和电脑必须在同一个 WiFi（别开 VPN/加速器）
- 电脑防火墙要放行 Python（第一次启动时弹窗选「允许」）
- 地址必须是 `http://` 开头 + 内网 IP + 端口，例如 `http://192.168.1.100:8787`

**在外面（4G）也想用？**
装 Tailscale（iPhone 和电脑都装、登录同一账号），然后把上面的地址换成电脑的 Tailscale IP，
例如 `http://100.101.102.103:8787`，出门在外也能记账和看账单。

**快捷指令提示「无法连接到服务器」**
iOS 有时会拦截明文 HTTP 到内网地址，把「获取 URL 内容」的方法确认为 GET、
并且不要在 URL 里写 `localhost`（要用电脑的内网 IP）。

**口令**
如果开了访问口令，每个链接后面加 `&token=你的口令`（第一个参数用 `?token=`）。
