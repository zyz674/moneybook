# 部署与使用

## 一、Windows 电脑（最省事，推荐先这么跑）

1. 安装 Python 3.9+（官网下载，安装时勾选 **Add Python to PATH**）
2. 双击 `run.cmd`
3. 窗口里会打印：

```
  本机：http://127.0.0.1:8787
  手机：http://192.168.1.100:8787   （手机需与电脑同一 WiFi）
  数据文件：...projectsmoneybookdatamoneybook.db
  账单投递目录：...projectsmoneybookdatainbox
```

4. 手机连同一个 WiFi，浏览器打开上面那个「手机」地址
5. 电脑首次启动如果弹出防火墙提示，选 **允许访问**（否则手机连不上）

**开机自启**：Win+R 输入 `taskschd.msc` → 创建任务 →
触发器「登录时」→ 操作「启动程序」填 `C:moneybookun.cmd`，
起始于填项目目录。

**窗口关闭后想让它继续跑**：把 run.cmd 里的 `python -m moneybook` 改成
`start /b pythonw -m moneybook`（无窗口后台运行，日志需要自己重定向）。

## 二、安卓手机（Termux，随身携带）

```bash
pkg update && pkg install python
# 把 moneybook 整个目录拷到手机（数据线 / 网盘 / git 都行）
cd ~/moneybook
./run.sh --port 8787
```

- 手机浏览器打开 `http://127.0.0.1:8787`，即用即走
- 想让它在后台常驻：`termux-wake-lock`（须在 Termux 通知里关掉电池优化）
- 自启：在 `~/.bashrc` 末尾加 `(cd ~/moneybook && nohup ./run.sh > ~/mb.log 2>&1 &)`
- Termux 版 Python 自带 sqlite3，无需额外安装任何依赖

**注意**：手机上的记账本和电脑上的记账本是两份独立数据（各自的 data/moneybook.db）。
建议只在一台设备上跑服务，其它设备用浏览器访问它。

## 三、Linux / 群晖 / VPS（长期在线，推荐）

```bash
cd /opt && git clone <你的仓库> moneybook   # 或直接拷目录
cd moneybook && chmod +x run.sh
nohup ./run.sh > moneybook.log 2>&1 &
```

systemd 常驻（`/etc/systemd/system/moneybook.service`）：

```ini
[Unit]
Description=moneybook
After=network.target

[Service]
WorkingDirectory=/opt/moneybook
ExecStart=/usr/bin/python3 -m moneybook
Environment=PYTHONPATH=/opt/moneybook/src
Environment=PYTHONUTF8=1
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload && sudo systemctl enable --now moneybook
journalctl -u moneybook -f
```

## 四、装到手机桌面（像 App 一样用）

**iPhone（Safari）**：打开地址 → 分享 → 添加到主屏幕。图标和名称会自动用 manifest 里的配置。
> iOS 必须用 Safari（Chrome 不支持添加到主屏幕）。

**安卓（Chrome / Edge）**：打开地址 → 右上角菜单 → 添加到主屏幕 / 安装应用。

局域网 HTTP 下 Chrome 不会显示「安装应用」的完整 PWA 入口（PWA 安装要求 HTTPS），
但「添加到主屏幕」的快捷方式一样好用，界面是全屏的。

---

## 五、异地使用（不在同一个 WiFi）

**不要**把端口直接映射到公网。按推荐顺序：

1. **Tailscale / ZeroTier**（最简单最安全）：两边装好组网，手机访问 `http://100.x.x.x:8787`
2. **WireGuard** 自建 VPN，同上
3. **frp / Cloudflare Tunnel + HTTPS**：暴露到公网时一定要设 `access_token`，并且只走 HTTPS

设了口令后，手机第一次访问会让你输入口令（也可以在地址后面加 `/login?token=你的口令` 直接登录）。

## 六、备份与迁移

全部数据就是 `data/moneybook.db` 一个文件（连同 `-wal`、`-shm` 一起复制更稳）。
备份：直接复制；迁移：把整个 `moneybook` 目录拷过去即可。
建议定期把 db 文件丢进网盘（它不包含你的登录密码，但包含全部消费记录，注意隐私）。

## 七、常见问题

**手机打不开地址**
1. 确认手机和电脑在同一 WiFi（手机别开流量/VPN）
2. Windows 防火墙放行：设置 → 网络和 Internet → 防火墙 → 允许应用通过防火墙 → 勾选 Python
3. 有些路由器开了「AP 隔离/访客网络」，设备之间不能互访，关掉即可
4. 用 `ipconfig` 确认电脑内网 IP 有没有变（重启路由器后可能变）

**端口被占用**：`python -m moneybook --port 9000`

**时间不对**：统一按北京时间（东八区）处理，机器时区异常会影响「今日」的口径

**通知抓取没有反应**
1. 打开「我的 → 最近任务」，如果里面没有 ingest 记录，说明手机端请求根本没到（检查 URL / 同一 WiFi / 口令）
2. 如果有记录但写着「未找到金额」，说明这条通知里确实没金额，把原文发我加规则
3. `saved: 0` 但 `ok: true` 一般是判定重复，属于正常

**账单导入后金额不对**
- 转账、还款、理财、已关闭订单会被标成「不计收支」，不计入收支统计（这是刻意的）
- 想看原始数据就点「导出 CSV」

**升级**：直接覆盖源码目录，`data/` 不要动，数据库结构会自动兼容。
